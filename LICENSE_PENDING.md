# Licence: decision pending

No licence has been chosen, so nothing in this repository is licensed for reuse yet. Choosing one is a decision for the authors and, given the University of Manchester's intellectual-property policy and the spin-out interests, for the university's technology-transfer office as well.

Suggested split, if the university has no objection: a permissive open-source licence for the code (MIT or BSD-3-Clause; Apache-2.0 if a patent grant is wanted) and Creative Commons Attribution 4.0 for the data files, logs and documents. The sealed-exam truth file and its SHA-256 should be published with the release so that readers can check that the predictions preceded the simulations.

Points to settle before any public upload: who holds copyright in code written with AI assistance (Nature Portfolio and most publishers do not accept an AI system as an author, and the AI-use statement belongs in the Methods); whether the repository should be public at submission or only at acceptance; and whether the held-back Level 3 reference data may be published, which is expected once Level 3 has been accepted.
